UniSpace - Research-Oriented University Information System

Project Overview
This project is a comprehensive console-based information system designed to manage academic workflows, user roles, and scientific research activities within a modern university. Developed by a collaborative team, it strictly follows OOP principles, implements layered architecture, and integrates business logic validation, data serialization, and design patterns to simulate a real-world educational environment.

Project Goals
Design a complete system architecture using Use Case & UML Class Diagrams
Implement role-based authentication and intuitive console navigation
Manage academic processes (course registration, grading, transcripts)
Track research activities with strict validation (h-index, supervisor rules)
Apply 4+ design patterns and custom exception handling
Ensure reliable data persistence through serialization
Deliver synchronized documentation, reverse-engineered diagrams, and presentation

Technologies Used
Core: Java 21
Architecture: Object-Oriented Design, Layered Architecture, Design Patterns
Data: Java Collections, Serialization API
Tools: IntelliJ IDEA, Git/GitHub, StarUML
Documentation: Javadoc, PDF Reporting & Presentation

Core Features
Secure authentication with role-specific console menus (Admin, Teacher, Student, Manager, Researcher)
Course management & registration (credit limits ≤21, multi-instructor assignment, major/year targeting)
Academic grading & reporting (attestation 1/2 + final, transcript generation, GPA/alphabetical sorting)
Research ecosystem (Researcher interface/decorator, h-index ≥ 3 validation, paper/project tracking)
Advanced sorting & analytics (custom Comparators for citations/date/length, top-cited researcher stats)
Business rule enforcement via custom exceptions (credit limits, max 3 fails, supervisor validation)
Data persistence via Java Serialization (Singleton/Repository pattern)
Implementation of 4+ design patterns (Factory, Singleton, Strategy, Observer/Decorator)
Full UML consistency with reverse engineering and detailed Javadoc documentation (5-10 classes)
